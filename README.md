# qed

Explain the essence of theorems.

## Purpose

`qed` distills theorems (and other mathematical results) down to their core
idea. Instead of reproducing a formal proof, it answers the question a learner
actually has: *why is this true, and what is really going on?*

- **Essence over rigor** — surface the key insight, the one idea that makes a
  theorem click, before the formal details.
- **Layered explanations** — start with intuition, then optionally drill into
  the precise statement and proof.
- **Theorem-first** — organized around named results (theorems, lemmas,
  identities) as the primary unit.

## Goals

- Turn intimidating results into a single clear takeaway.
- Complement, not replace, formal treatments.
