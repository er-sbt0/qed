Tychonoff · scene I — the myopia of the product topology

An open set can only ever pin down finitely many coordinates.

A point of {0,1}ℕ is an infinite row of switches. A basic open set is a mask: a few switches clamped, and every other one left wide open — the loud amber columns, which is where almost all the content is. Click the strip under a column to clamp or release it. Then throw the box switch and watch the count go to infinity.

the rackWidths recede geometrically. The terminal glyph is a control, not an ellipsis — press it and coordinate 10,000 turns out to look exactly like coordinate 3.
the maskFree columns are rendered loudest. Every naive drawing dims them, which inverts the meaning: freedom is the content of the theorem.
the countOne number carries the whole scene. Finite in the product topology, infinite in the box. Everything else is commentary.
the box beatClamp all of them and the open set has exactly one point in it. Singletons open, uncountably many of them, no finite subcover — Tychonoff dies precisely here.
