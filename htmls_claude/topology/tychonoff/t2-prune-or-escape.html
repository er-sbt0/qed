Tychonoff · scene II — compactness you can run

Prune the claimed subtrees. You either finish, or you fall forever.

A point of {0,1}ℕ is a path down the tree; a cylinder is a whole subtree. Walk from the root: if some cylinder already owns everything below you, cut and step back. Otherwise go deeper. Every run ends one of two ways — a finite list of cylinders that did the job, or a branch nobody claimed, which is the point the cover missed. That dichotomy is König's lemma, and here it is Tychonoff.

one address, two picturesEvery node carries a bit string. The slider moves it between the dyadic position that makes a tree and the triadic position that makes the Cantor set — one object, not two illustrations.
stepped, not instantThe order of the walk is where the finiteness comes from, so the eye has to see it happen. Step through it once before pressing Run.
the two verdictsA finite subcover is a list. A failure is a point. Both are concrete objects the walk hands you — no proof by contradiction required.
why it terminatesEvery cylinder is decided by some finite depth. Past the deepest one, a node is either already owned or free forever, so the walk cannot run long without escaping.
