Tychonoff · scene III — Alexander's subbase lemma

If nothing can pin you down in any single coordinate, nothing can pin you down at all.

Suppose a cover made only of subbasic sets — each one constrains exactly one coordinate — has no finite subcover. Then no single factor is fully covered by the slices used there, because [0,1] is compact and finitely many slices would have sufficed. So each coordinate leaves a survivor. Collect one from each, and the assembled point sits outside every set in the cover. The family was never a cover at all.

one tooth eachA subbasic set constrains a single coordinate. That is the whole reason this argument can be run coordinate by coordinate.
the gap is the pointCompactness of the factor is used in the negative: a gap survives precisely because the slices failed to cover [0,1].
the assemblySurvivors slide into one column and become a single point of the product. Nothing is approximated — the point is exhibited.
choice, shown not hiddenThe marker hovers among equally good candidates before settling. Tychonoff is equivalent to AC; a figure that quietly picked midpoints would be lying about the theorem.
